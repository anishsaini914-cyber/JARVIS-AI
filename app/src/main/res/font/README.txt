JARVIS uses Space Grotesk and Inter fonts.

To include these fonts:
1. Download Space Grotesk from https://fonts.google.com/specimen/Space+Grotesk
2. Download Inter from https://fonts.google.com/specimen/Inter
3. Place the .ttf or .otf files in this directory
4. Create font family XML files referencing them

Required files:
- space_grotesk.xml (font family)
- inter.xml (font family)

Or simply remove the fontFamily references from themes.xml to use system fonts.
